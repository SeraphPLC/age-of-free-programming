# Version history

## v0.1 — October 2026 — Original Community Preview

- Preserves the free copy-and-paste educational **Build Your Own AI OS** master prompt provided for public distribution.
- Offline-first Python 3 + SQLite + unittest system outline, mission binder, permission gates, status reporting, task ownership, resumable handoff, verified backups.
- Explicitly not an installed program, verified autonomous agent, or official Seraph product.
- File: [Original master prompt](prompts/BUILD_YOUR_OWN_AI_OS_v0.1.md).

## v0.2 CANDIDATE — 2026-10-24

- Tightens event-to-state reconciliation, separate-process claim testing, symlink/path containment, and provenance of test receipts.
- Clarifies that owner names and hashes are not identity/authentication.
- Requires fresh approval per privileged action, excludes inherited permission from a Resume Card, and adds privacy rules for claim handles.
- Keeps the reference executable **out of the public release** pending further verification.
- File: [Hardened candidate](prompts/BUILD_YOUR_OWN_AI_OS_v0.2_CANDIDATE.md).

### Release discipline

A change to prompt instructions is not proof that AI builders faithfully implement it. Candidate promotion requires independent clean-room runs, evidence, correction of observed defects, and clear limitation statements.

## v0.3 KNOWLEDGE ARCHITECT CANDIDATE — 2026-10-24

- Adds a self-contained optional knowledge architecture to the v0.2 educational master prompt, without changing the archived v0.1 original.
- Recreates only the **general functions** of older-style engineering canon, lexicons, evidence registries, defect records, historical archives, and restart packets; it does not reproduce private Seraph files.
- Introduces source rights and metadata registers, a tiny local-first search index, explicit Kiwix/encyclopedia/public-domain/scientific source categories, safe admission gates, and model/provider routing with clear intended roles.
- All downloads, installs, APIs, network and bulk archiving remain **OFF BY DEFAULT**.
- Full guide: [AI models and large knowledge resources](docs/AI_MODELS_AND_MASS_KNOWLEDGE_GUIDE.md).
- Exact builder prompt: [v0.3 Knowledge Architect](prompts/BUILD_YOUR_OWN_AI_OS_v0.3_KNOWLEDGE_ARCHITECT_CANDIDATE.md).
- No independent cross-model builder replay or complete security/reuse audit has been performed on v0.3.

## v0.4 MEMORY FIDELITY CANDIDATE — 2026-10-24

- Preserves public v0.1–v0.3 unchanged while publishing a new complete v0.4 educational master prompt.
- Adds model-independent, source-grounded memory event journaling; verified/candidate separation; contradiction, correction, invalidation and deletion lifecycle; fresh-process and fresh-chat reconstruction; explicit non-inheritance of permissions.
- Adds two **original, standalone, JSON Schema Draft 2020-12** data contracts with fictional example records: memory event and sanitized restart packet. The schemas validate shape; they do not prove consent, authentication, truth or safety.
- Adds a 22-scenario adversarial test plan with measurable fidelity, data-loss, privacy and authority checks. All new tests are NOT RUN until an actual implementation reports receipts.
- Adds a strict no-backlink design contract: no cloud callbacks, telemetry, private systems, secret data, background workers or mandatory external providers.
- [v0.4 full prompt](prompts/BUILD_YOUR_OWN_AI_OS_v0.4_MEMORY_FIDELITY_CANDIDATE.md) · [memory design](docs/MEMORY_FIDELITY_V1.md) · [schemas](schemas/memory_record_v1.schema.json) · [test plan](docs/MEMORY_FIDELITY_ACCEPTANCE_V1.md).
