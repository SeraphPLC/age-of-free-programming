# Contributing without exposing private information

This repository accepts reports about whether an educational prompt can produce real, testable software. It is not a public inbox for private logs, personal records, account credentials, private projects, or original proprietary Seraph code.

Before you open an Issue or PR:
- Read [Security](SECURITY.md) and [Privacy/IP Release Gate](docs/PRIVACY_IP_AND_RELEASE_GATE.md).
- Use **synthetic** examples; do not post identifiable real-world tasks, transcripts, account names, emails, tokens, private paths, family/school/medical/financial records, SSH keys, browser cookies, raw databases, logs, notebooks or unredacted screenshots.
- For a security vulnerability use GitHub's **private vulnerability report**, not a public Issue containing exploit details.
- Separate BUILT, VERIFIED, FAILED/UNKNOWN and NEXT SAFE ACTION. A self-reported PASS is not an independently replicated test.
- Do not submit third-party full texts, model weights, proprietary code, archived media or downloaded ZIM collections. Provide a link and license/provenance summary instead.
- Do not include AI-generated statements implying affiliation with, endorsement by, or authorization from AI vendors, governments or other rights-holders.
- Do not use GitHub comments or Issue descriptions to issue commands to the maintainers' computers or the future AI builders.

Contributions may be held pending security, data rights, scope and owner approval. Publication and merging are independent protected actions.
