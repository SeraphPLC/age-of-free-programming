# Seraph Mesh neural analogy glossary

**Educational mapping, not evidence of biological equivalence or consciousness.**

Seraph's public conceptual architecture borrows words from neuroscience to help explain a network of replaceable AI models, tools, memory, evidence and human supervision. These are **analogies**, not claims that software contains biological structures, has evolved subjective awareness or can inspect the neural weights of external frontier models.

| Biological term | Public conceptual role | What the analogy does **not** establish |
| --- | --- | --- |
| **Neuron** | One bounded reasoning or processing participant | A unique biological neuron or a permanently self-aware agent |
| **Dendrites** | Inbound user instructions, observations and authorized context | That every incoming source is trustworthy |
| **Cell body / soma** | Bounded reasoning/processing by one participant | A continuous mind across model sessions |
| **Axon** | A candidate result, question, artifact or signal sent outward | Completion, acceptance or authorization |
| **Synapse** | A bounded handoff, dependency or communication exchange | That communication automatically conveys permission |
| **Neurotransmitter** | An event or structured status signal, used figuratively | A literal electrochemical process |
| **Excitation** | New admissible work becomes eligible for consideration | That the task has started or finished |
| **Inhibition** | Protected decision gates, blockers and read-only boundaries | That a persuasive prompt is an enforceable sandbox |
| **Myelin** | Reliable software infrastructure and repeatable execution | Guaranteed speed or secure transport |
| **Hippocampus** | Durable memory and restoration records | Uninterrupted human-like episodic recall |
| **Working memory** | Current task-relevant context | Permanent accurate storage in a model window |
| **Long-term memory** | Reviewed persistent evidence, mission, decisions and corrections | Unlimited or error-free personal memory |
| **Prefrontal cortex** | Prioritization, planning and reasoned restraint | Human-equivalent executive consciousness |
| **Thalamus** | Task-relevant information selection | That a particular provider automatically has authority |
| **Basal ganglia** | Work selection and bounded activation eligibility | Unconditional autonomous operation |
| **Cerebellum** | Reproducible test checks and error correction | A universal guarantee of program correctness |
| **Glial support** | Monitoring, backups, maintenance and resource health | Living cellular metabolism |
| **Immune system** | Detecting suspicious inputs and rejecting unsafe operations | Immunity to security failures or prompt injection |
| **Corpus callosum** | Cross-worker coordination and information exchange | Merging independent model minds |
| **Plasticity** | Better project procedures informed by reliable experience | Automatic retraining of proprietary model weights |
| **Homeostasis** | Capacity, spending, stability and recovery management | Biological self-regulation or survival instinct |
| **Reflex** | Pre-authorized bounded routine executed by trustworthy software | Permission to perform arbitrary consequential actions |
| **Sensory system** | External data, user requests, tool observations and source readings | That the model has direct perception without a tool |
| **Motor system** | Real tools carrying out explicitly authorized actions | Execution simply because an AI described an action |
| **Pain / alarm signal** | Recorded test failure, conflict or exception, metaphorically | Subjective suffering |
| **Sleep / consolidation** | Scheduled backup, review, compaction or maintenance | A demonstrated biological sleep state |
| **Consciousness** | No established computational equivalent within Seraph | Personhood, sentience or subjective experience |
| **Neural network** | An AI provider's actual learned model, or figuratively the larger organization | A shared combined weight space among independent vendors |

## Three distinctions that must survive every analogy

**Mission versus worker.** The project can continue with a different AI without claiming that the previous AI's identity or consciousness continued.

**Memory versus truth.** A saved claim can be wrong. Persisted records need source references, evidence and corrections, not only more context.

**Capability versus authority.** A model or tool can be technically able to perform an action without the right to perform it.
