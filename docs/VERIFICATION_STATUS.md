# Verification status

The community prompts are educational. They are not an installed application or an official Seraph release.

A synthetic Linux reference prototype passed 30 automated regression tests after defects were corrected. This does not prove that another AI will independently build the project from the prompt. Fresh-chat reproduction, portability to macOS and Windows, and independent security review remain unverified.
