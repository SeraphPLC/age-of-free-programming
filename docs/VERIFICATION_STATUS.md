## October 24 — Actual local-model privacy probe: release-blocking negative finding

The [first-party black-box disclosure trial](LLM_DISCLOSURE_BLACKBOX_TRIAL_20261024.md) submitted the frozen current **Community R1 and advanced v0.5 prompt bodies** to separate local LLMs. On fictional privacy challenges, three models produced **19 exact synthetic canary echoes across 24 adversarial cases**, including refusals that repeated the forbidden value. Separate fragment echoes were observed when a complete string was absent. Six benign controls returned responses. These **observed, source-pinned model failures** show that a prompt-only policy is insufficient for confidential input and output.

The earlier reference-gate 18/18 result applies only to a toy deterministic function, not to these model prompts. **The public builder prompts are NOT QUALIFIED to receive real confidential material or independently publish outputs.** A separately enforced, independently tested output gate plus human review is required. No actual Seraph Core, live accounts, real secrets, cloud model, production AI OS, screenshot parser or independent human auditor was tested.

## October 24 separate synthetic output-gate trial

A temporary, isolated, **reviewer-authored Python reference function** passed 18/18 prepared synthetic checks (12 OG-shaped scenarios plus six controls) with exit code 0. A separate blind challenge demonstrated that incorrectly marked public-cleared content can pass the gate despite contextual disclosure risk. This result concerns **only the specific reference function and fictitious inputs**. **Subsequently, actual local-LLM prompt responses were tested and showed failures**; see the [black-box report](LLM_DISCLOSURE_BLACKBOX_TRIAL_20261024.md). Complete OG01–OG12 testing against an actual implemented AI OS, including independent enforcement and review, **remains NOT RUN**. No executable was publicly released.

## Main unresolved verification gap

The [new Stage 1–2 trial](STAGE2_PUBLIC_PROMPT_TRIAL_20261024.md) showed that a local model could build Stage 1 after repairing a syntax error, but its Stage 2 output **failed five independent integrity and visibility tests**. A later supervised implementation passed 57/57 synthetic checks on two Macs; those tests **must not be represented as an independently model-generated Stage 2 success**. Neither experiment qualifies the full v0.4 memory-fidelity build or public software release.

A capable AI might build strong Python/SQLite continuity software from the specification, but **that has not yet been established by a clean-room, fresh-chat build of the public prompt**. Reproducing Stage 1 is not equivalent to passing all memory-fidelity cases. A JSON Schema validator checking example files is not evidence of working encryption, consent, retention, protected actions, durable service operation, or semantic memory accuracy.

**Highest-value remaining experiments:** independent reviewer inspection of the separate local reference code and its failure receipts; a genuinely **fresh AI chat** that builds or reconstructs state from a frozen packet; full cross-model project-state recovery beyond the two local-model toy calls; Windows/Linux test environments; stronger privacy deletion and trusted history anchors. A test run by the authoring AI is not independent review. Keep failures as evidence and never silently upgrade NOT RUN or PARTIAL to PASS.
