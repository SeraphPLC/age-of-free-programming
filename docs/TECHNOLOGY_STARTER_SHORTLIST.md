# Practical software choices: start small

The [304-option research atlas](AI_DEVELOPMENT_OPTION_UNIVERSE_V1.md) is a **discovery appendix**, not a shopping list, installation inventory, quality ranking, license clearance or evidence of which tools the publisher uses. Software catalogs change quickly. Review current official terms before choosing an option.

| Priority for a beginner | Option | Why you would choose it | Default exposure |
| --- | --- | --- | --- |
| 1 | No AI runtime | A handoff text file with a verified current revision | No model/provider dependency |
| 2 | Python 3 + SQLite | Durable offline task ledger and backup via built-in libraries | No network needed after initial legitimate installation |
| 3 | `unittest` | Actual repeatable negative tests and proof of completed work | Built into Python |
| 4 | Git (optional) | Version small nonprivate project instructions and source code | Local repository possible; remote syncing optional |
| 5 | A user-authorized code-capable assistant | Generate code in an approved new folder; inspect/test the work | Cloud prompts and computer permissions require review |
| 6 | Local model runtime (optional) | Offline text-generation with an approved downloaded model | Storage/CPU cost; validate actual network behavior and model license |
| 7 | SQLite FTS5 (optional) | Search permitted small local source text | Check Python/SQLite build support |
| 8 | Kiwix/library index (optional) | Read legally obtained offline knowledge with verified reader | Archive licenses, freshness, storage and retrieval tests |

**Selection rule:** First prove that the simplest version solves the problem. Any new package, API, corpus, model, network listener, installer or account integration introduces additional privacy, legal, security or cost obligations and needs owner approval.

The **real differentiation** of the advanced specification is evidence validation, negative testing, controlled authority, and correct reconstruction after interruption—not the number of model brands it lists.
