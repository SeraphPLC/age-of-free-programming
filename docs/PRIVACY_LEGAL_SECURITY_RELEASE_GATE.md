# Release safety policy — compatibility link

**Controlling policy:** [Privacy, Intellectual Property and Public Release Gate](PRIVACY_IP_AND_RELEASE_GATE.md).

This file is retained because earlier public materials may link to it. It is not a second conflicting release policy. The controlling document covers identity/commit history, private-source boundaries, licensing and third-party content, malware/supply-chain risk, explicit action authority, public claims, and release approval. The [sharing status](SHARING_AND_LICENSE_STATUS.md) determines what may be freely copied. The [security reporting policy](../SECURITY.md) governs confidential vulnerability reports.

**Standing boundaries:** Only original rights-cleared educational text and fictional examples are eligible for the default public guide. Do not include private Seraph source, hardware details, unpublished research, real personal records, third-party bulk archives, model weights, credentials, callbacks, telemetry or executable installers. Do not grant remote or account permissions by implication. Human review is required for new software, data or model releases; no legal or security professional has certified this project.

For user protection, public GitHub Issues remain disabled and no personal build logs are requested. The project provides no blanket open-source or commercial content license at present.

**This policy pointer creates no additional license or claim of zero legal/privacy risk.**
