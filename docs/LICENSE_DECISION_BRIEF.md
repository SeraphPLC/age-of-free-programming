# Proposed license choices — **NO LICENSE HAS BEEN SELECTED**

This public repository currently invites people to copy the educational prompts into their own AI chats and share links. That is **not** the same as a clear permission to modify, fork, redistribute, translate, publish derived editions or commercially redistribute all repository text.

A rights-holder must establish that it has the authority to license the **specific original material** and separately verify that no private project expression, third-party material or unlicensed generated snippets were included. Choosing a license for one's own text does not grant rights to someone else's code, trademarks, model weights or source archives.

## Possible choices for a future explicit decision

| Material | One plausible option | What it means / important caveat |
| --- | --- | --- |
| Original public educational *prompts and documents* | **CC BY 4.0** | Permits adaptation and commercial redistribution with attribution; irrevocable for compliant recipients. Requires rights-holder approval and precise scope. |
| Original public educational *prompts and documents* | **CC BY-SA 4.0** | Similar, but share-alike for adaptations; not a software-code license. |
| Original source code **if separately developed and approved** | **MIT** | Permissive reuse with copyright/license notice. Does not cover datasets/third-party sources automatically. |
| Private/proprietary documents | **Do not license here** | Keep entirely outside this repository without explicit owner clearance. |

**No current action:** Do not add a root MIT/CC license or assert "open source" until an authorized rights-holder selects a scope and the repository's text/code/data/IP are reviewed. The fact that a prompt is given away for free does not itself place it in the public domain. A legal professional can advise on contributors, copyrightability of generated text, trademarks, commercial sublicensing and international reuse.

## Checks before a decision

- Confirm which legal person/entity actually owns each file and authored expression.
- Check real third-party text, images, model weights, source code and noncommercial restrictions.
- Choose whether the goal is free personal use only, open modifications, commercial use, mandatory attribution or share-alike.
- Apply the explicit license to **specified files or a clearly defined scope**, preserving existing third-party notices.
- Communicate what was licensed and what remains excluded. Record approval and release date.
