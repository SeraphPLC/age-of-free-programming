# No personal data collection

Public GitHub Issues are disabled. The free educational prompt does not require registration, account data, telemetry, diagnostics, log upload, personal information or any build report. GitHub and any user-selected AI provider may process data under their own terms.

Use the [optional offline self-check](BUILD_REPORT_TEMPLATE_OFFLINE.md) and keep it on your own device.

The project does not operate a user database, login service, tracking pixel or application backend. Future forms, analytics, mailing lists, cookies, connected accounts or data collection require separate owner authorization and a suitable privacy review.

Always use made-up examples. Never submit passwords, private data, chat exports, payment records or unredacted code.

Sensitive vulnerabilities should be submitted privately through [security reporting](../SECURITY.md), not social media.

Local-first guidance is not a guarantee that a user-selected AI vendor processes their conversations locally.
